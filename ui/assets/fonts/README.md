# Satoshi Variable font

`Satoshi-Variable.ttf` is supplied locally in this directory and is packaged
with Silly. The UI registers this exact local file as the `Satoshi` variable
face with the supported 300–500 weight range. It is not downloaded at runtime.

Satoshi is an Indian Type Foundry typeface distributed through Fontshare. Its
supplied Fontshare Free Font EULA is retained verbatim in
`Satoshi-Fontshare-EULA.txt`. Review that license before distributing a build
that embeds this font.
